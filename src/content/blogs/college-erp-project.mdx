## Project overview

College ERP is an academic management application developed between August 2025 and January 2026 using Django, Python and SQL.

## Core workflows

The application covers admissions, attendance, timetables, examinations, assignments and academic records. Role-based dashboards provide separate access for administrators, teachers and students. Notices, messaging, document vault, leave requests and counseling support cross-department workflows.

## Recognition

The project won first prize at the Technophilia Technical Project Expo in April 2026, among participants from multiple colleges and cities.
